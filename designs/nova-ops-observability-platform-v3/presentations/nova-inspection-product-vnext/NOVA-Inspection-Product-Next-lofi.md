# NOVA 巡检产品下一版方案 — 低保真稿

> **受众**：产品负责人、SRE/平台工程负责人、技术决策者
> **风格**：自定义 NOVA 深色运维视觉
> **视觉**：深黑蓝背景 + 珊瑚红决策强调 + 青绿色证据强调
> **页数**：10 页（含封面）
> **原则**：只保留能驱动产品决策的内容；每页一个明确结论
> **输出覆盖**：HTML 单文件，可键盘/触控翻页，移动端可读，离线零外链

## P6：主旅程｜一次变更贯穿计划、执行、比较、治理和归档

    计划
    选择服务 → 快照 → 候选项 → 草稿 CRUD → 发布 Revision

    执行
    创建 Case → 变更前 → 灰度/验证 → 风险处置 → 复验 → 变更后

    决策
    阶段报告 → ComparabilityContract → 前后对比 → Finding → FinalReport

**视觉指引**：

- 页面类型：三泳道旅程页
- 三条泳道分别使用灰、青、红标识“计划/证据/决策”
- 每个阶段在下方标出用户可见终态

    │ timeline      │ [继续] [阻断] [整改] [复验]   │ 起草治理建议   │

    Mobile：范围 → 方案 → 执行 → 对比 → 报告；Claw 为底部抽屉。

**视觉指引**：

- 页面类型：产品工作区线框图
- 中部占 55%，左侧 22%，右侧 23%
- 顶部固定显示 service/change/stage/comparability/gate
- omissions 必须首屏可见，不能藏在 hover 或详情页

## P8：证据边界｜缺失证据必须被诚实地显示

    ┌─────────────────────────────┐  ┌───────────────────────────────┐
    │ 机器判定                    │  │ 人工决策                      │
    │ PASS / WARN / FAIL          │  │ ACCEPT / HOLD / WAIVE         │
    │ UNKNOWN / ERROR             │  │ 不能覆盖机器证据              │
    └─────────────────────────────┘  └───────────────────────────────┘

    Case 无任何采证：
      ABANDONED_BEFORE_EXECUTION → 新建 successor

    Case 已有 Run / Evidence / Decision：
      BLOCKED_WITH_PARTIAL_EVIDENCE → 冻结部分报告 → 新建 successor

**视觉指引**：

- 页面类型：双栏证据论证页
- 机器状态与人工决策明确分列
- 下半部用两条生命周期分支表达“未执行”和“已采证”的区别

## P9：一期｜小而完整，而不是功能列表

    ┌────────────────────────────────┬───────────────────────────────┐
    │ 一期包含                       │ 明确不做                      │
    │ 单跳 replay/sandbox 快照       │ 生产自动拓扑发现              │
    │ 候选项 + provenance/omissions  │ 自由 DAG 编排器               │
    │ 草稿 CRUD + 不可变 Revision    │ 自动调度                      │
    │ 变更前 / 灰度 / 变更后         │ 自动发布/扩缩容/回滚           │
    │ 阶段报告 + 对比 + 风险 + 复验   │ Claw 无确认直接执行           │
    └────────────────────────────────┴───────────────────────────────┘

**视觉指引**：

- 页面类型：范围 VS 页
- 左侧为青绿色勾选，右侧为灰红色排除
- 中央大字：完整闭环，不假装生产能力

## P10：路线图｜先把证据链做对，再扩大连接与治理

    Phase 1                    Phase 2                    Phase 3
    受控依赖感知闭环          真实只读连接              治理运营
    replay/sandbox             service catalog           审批与责任
    三阶段执行                 topology connector        受限调度
    阶段/最终报告              revision diff             工单链接
    风险复验                   历史风险趋势              风险复发分析

    成功标准：
    10 秒内说清“为什么查、查了什么、能否比较、风险是什么、下一步做什么”。

**视觉指引**：

- 页面类型：三阶段路线图
- Phase 1 最高亮，Phase 2/3 逐渐降低视觉权重
- 底部以一句成功标准收束，不放“谢谢”

## HTML 实现指引

**风格 preset**：自定义 NOVA 深色运维视觉

- 背景：#070B12
- 卡片：#111925 / #172131
- 决策强调：#FF5C72
- 证据强调：#56D6C2
- 注意：#F5B942
- 主文字：#F4F7FB
- 次级文字：#94A3B8

**交互**：

- 键盘方向键、PageUp/PageDown、空格翻页
- 点击控制按钮
- 触控左右滑动
- F 键或按钮进入全屏
- URL hash 记录当前页
- 打印模式展开所有页面

**离线约束**：

- 单文件内联 CSS 与 JavaScript
- 不引用外部字体、脚本、样式或图片
- 无网络请求
