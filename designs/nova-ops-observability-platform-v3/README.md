# NOVA 变更巡检智能工作台

这是一份可点击、可离线打开的高保真产品原型。它延续 `75d991e` 已确认的信息架构，不再另造能力门户或 Dashboard：

- 左侧是沉淀的历史巡检任务、最近结果与报告评分；
- 中间是选中任务的方案、实时证据、当前结论和最终报告；
- 右侧是 CLAW 的实时对话与生成工作流；
- 下方是具体执行计划、依赖、状态和不可变证据时间线。

原型集中回答两件事：

1. 如何把自然语义、变更指导书和业务知识图谱融合成可解释的巡检任务；每个检查项都能展开生成理由、置信度与来源。缺少业务知识时会阻止生成，不会用通用检查项冒充业务方案。
2. 如何把巡检报告变成直观结论；报告提供总分、覆盖完整度、证据可信度、基线可比性、证据新鲜度、风险闭环度、剩余风险和引用证据，CLAW 只解读不可变报告，不改写结论。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:5290/`。

## 单文件电脑演示

直接下载
[`NOVA-Ops-Intelligence-Standalone.html`](./NOVA-Ops-Intelligence-Standalone.html)
并双击打开即可。文件内已经包含全部样式、交互代码和固定 Mock 数据，不需要安装
Node.js，不需要启动进程，也不会访问网络或连接生产系统。

演示建议从左侧“巡检任务”选择“库存服务发布巡检”，先核对中间的三类知识来源和检查项生成理由，然后依次执行：

1. 确认方案并执行变更前巡检；
2. 批准进入 25% 灰度；
3. 记录模拟风险处置并执行复验；
4. 继续到 100% 放量；
5. 执行变更后验收，查看报告评分、剩余风险和引用证据；
6. 请 CLAW 解读最终报告，确认解释来自同一份报告快照。

历史任务只复用检查方案；每次演示都会创建新的 Mock Run 和报告，不会沿用上一条任务的证据。也可以点击“新建巡检”，输入 `payments-router v3.18.0` 体验自然语言入口；输入未接入知识库的服务会看到 fail-closed 的缺口说明。

需要从源码重新生成时运行：

```bash
npm run build:standalone
```
