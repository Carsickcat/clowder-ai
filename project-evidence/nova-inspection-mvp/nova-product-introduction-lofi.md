# NOVA 变更巡检产品介绍 — 低保真蓝图

> **受众**：产品验收者、SRE、平台负责人
> **场景**：产品走查、内部汇报、最小可运行项目交付
> **风格**：NOVA 自定义深色决策驾驶舱
> **视觉**：墨绿黑底、低饱和面板、荧光绿证据锚点、琥珀色风险提示
> **页数**：8 页（16:9）
> **原则**：核心价值与可信边界优先；用真实隔离链路衍生的 Mock 数据证明产品闭环

## 精美图生成 / HTML 实现指引

- **风格 preset**：NOVA 自定义深色决策驾驶舱；不使用通用企业白底模板。
- **主色**：荧光绿 `#63E6A8`；风险提示琥珀 `#F4C96D`；背景墨绿黑 `#050B0A`。
- **排版**：16:9；大标题低字距；卡片细边、弱底色；每页只保留一个核心结论。
- **交互**：左右方向键、PageUp/PageDown、空格翻页；Home/End 跳转；打印时每页独立分页。
- **数据纪律**：P7 始终显示“合成验收数据”；不把 Mock 结果表达成生产事实。
