# NOVA deck mobile slide overlap

## Bug 诊断胶囊

| 栏位             | 内容                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------- |
| 现象             | 390×844 视口打开第 7 页时，封面与当前页同时显示；期望任何视口只显示一个 active slide。 |
| 证据             | 视觉截图出现两页叠加；浏览器回归测得可见 slide 数量为 2。                              |
| 根因             | 窄屏规则使用 .cover display 覆盖，选择器优先级越过了基础 .slide 隐藏规则。             |
| 诊断策略         | 对照桌面显示规则并读取窄屏 computed style；把“可见 slide 数量”固化为浏览器断言。       |
| 超时策略         | 单一选择器修复若不生效，停止叠加规则并改为统一 active-state 渲染入口。                 |
| 预警策略         | 若其他页面类型也需要单独的 display 覆盖，说明 active-state 与 layout 职责再次耦合。    |
| 用户可见交互修正 | 手机打开任意页只显示当前页，纵向滚动仅发生在当前页内部。                               |
| 验收             | deck-browser.test.mjs 在 390×844 断言可见 slide 数量为 1；桌面 10 页均不垂直溢出。     |

## 五件套

1. **报告人**：丢丢；在 browser-preview 后的手机视觉截图中发现。
2. **复现步骤**：手机宽度打开 HTML，导航至第 7 页；修复前封面仍保持 display:block。
3. **根因分析**：移动端页面类型样式错误地承担了 active-state 显示职责，覆盖基础隐藏规则。
4. **修复方案**：将窄屏规则限定为 .slide.cover.active，不再改变非 active slide 的显示状态。
5. **验证方式**：浏览器合同覆盖桌面/手机、键盘导航、单页可见性、横向溢出与截图。
